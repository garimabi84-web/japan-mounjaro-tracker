# 일본 마운자로 병원 발굴형 가격 추적기 v3

**기초 조사: 2026-11-20 · 28개 비교 항목(병원 방문/온라인 분리 포함) · 공개 SNS·웹 발견 근거 7건 · 이벤트 기록 3건**

## 2026-11-21: 한국인 관광객 중심 SNS 발굴 개선 (v4)

- **검색 순서:** 한국인·외국인 방문객 대상 SNS 광고와 12펜 이벤트, LINE 예약·호텔 배송 관련 공개 검색을 우선합니다. 일본어·한국어 Bing 검색, 공개 Yahoo X 검색, Google News를 혼합하고, 지역 검색어는 순환합니다.
- **외부 목록은 이름 발견용:** 외국인 진료를 다루는 공개 병원 목록을 보조로 참조하더라도, 이름과 출처만 후보로 저장합니다. 가격·처방·예약 가능 여부를 외부 비교 사이트에서 자동으로 복사하지 않습니다.
- **가짜 병원명 제거:** 종전 파서가 '이번에 소개받은 클리닉' 같은 문장을 병원명으로 기록하던 문제를 수정하고 기존 오탐 후보를 비교표에서 정리했습니다. 원문 발견 기록은 후속 확인에 쓰도록 아카이브에 남깁니다.
- **검증되지 않은 후보는 기본 숨김:** 웹 대시보드에서 '미검증 SNS 후보 포함'을 켜면 확인할 수 있습니다. 기본 순위는 병원·가격 근거가 확인된 항목을 대상으로 합니다.
- **한국어 공식 홍보 페이지 기반 추가:** JAPAN WEB CLINIC, 미라이 메디컬, 슬림클리닉, UB 온라인, 라피스 텐진, 오카치, 재팬넷클리닉 등의 가격·진료·예약 정보를 출처별로 구분해 추가했습니다. 가격 근거가 없는 용량은 비워둡니다.
- **수동 심층검색:** GitHub Actions → Find new clinics → Run workflow에서 `full_scan`을 켜면 모든 설정된 SNS·지역 검색어를 실행합니다. 정기 실행은 시간·검색량을 제한하기 위해 지역·SNS 검색어를 순환합니다.
- **가격 검증 후보 순환:** 이전에는 항상 첫 12개만 검사했지만 이제 최근에 시도하지 않은 후보부터 확인합니다.
- **한계:** SNS 플랫폼의 로그인 제한이나 검색엔진 색인 누락을 우회하지 않습니다. '검색 요청 성공'은 '신규 병원 발견 성공'과 다릅니다. 마운자로 12주 가격은 실제 일괄 처방을 보장하지 않습니다.

## 재검색 버튼 사용법 (2026-11-21)

웹사이트 ‘공개 SNS·웹 신규 발굴 내역’의 **수동 재검색** 버튼은 GitHub Actions의 안전한 실행 화면을 엽니다. GitHub에 저장소 쓰기 권한이 있는 계정으로 로그인한 뒤 **Run workflow → Run workflow**를 선택하면 실제 SNS·웹 검색을 실행합니다. 수동 실행의 `full_scan`은 기본 ON으로 설정되어 전체 지역·SNS 검색어를 순회하며, 매일 정오 자동 실행은 부담을 줄이기 위해 지역별 검색어를 순환합니다. 완료 후 사이트의 **최신 결과 불러오기** 버튼을 누르면 캐시를 피해서 최근 배포 화면을 요청합니다. GitHub Actions 또는 Pages 배포가 끝나기 전이면 이전 데이터가 표시될 수 있습니다.

정적 GitHub Pages는 인증 권한이 없어서 사이트의 버튼 한 번만으로 비공개 GitHub Actions 작업을 시작할 수 없습니다. 접근 토큰은 사이트에 포함하거나 공개 저장소에 저장하지 않습니다. 사이트에 표시하는 실행 안내는 누구나 볼 수 있지만, 실제 작업을 실행할 권한은 저장소 소유자 등 쓰기 권한이 있는 계정에만 있습니다.

## 요구사항별 동작

1. **병원 발굴부터:** `discover.py`가 매 회차 공개 SNS 색인 결과(X·Instagram·Facebook 대상으로 Bing RSS 검색), 공개 Yahoo! Japan X 실시간 검색 및 Google News 공개 RSS를 조회합니다. 게시물에서 병원명을 인식하면 `catalog.json`에 중복을 걸러 새로운 **candidate** 레코드를 만듭니다. 이름, 공개 검색/게시물 링크, 발견 경로와 기록을 남깁니다. 새 병원은 코드의 고정된 목록에 수동 등록할 필요가 없습니다.
2. **발견된 병원의 가격 검증:** `enrich_official.py`가 새 후보를 대상으로 병원 공식 가격표를 검색하고, **12펜/3개월 가격이 명시되어 있거나 4펜/1개월 가격이 분명할 때에만** 12주 값을 추출해 비교표에 채웁니다. 가격을 안전하게 판별할 수 없다면 `후보·가격검증 전` 상태로 남깁니다. 외국인 수진, 온라인 진료, 전국 배송은 **근거 없이 '가능'으로 자동 분류하지 않습니다.**
3. **이벤트도 가격에 포함:** `catalog.json`의 `events[]`에 12펜 행사 금액, 기간, 조건, 출처를 별도로 넣습니다. 기간 내 행사 금액은 **일반가와 함께 최저가 비교**에 사용됩니다. 화면에서 `이벤트` 배지를 표시하며, 종료하면 비교가에서 자동 제외됩니다. `종료된 행사 가격도 비교`를 선택하면 과거 행사 가격도 별도로 확인할 수 있습니다. **이미 종료된 행사가 현행 최저가로 오인되지 않도록 표시됩니다.**
4. **기존 가격 추적:** `watch_sources.py`는 등록된 공식 가격 페이지 내용의 변경을 감시합니다. 검증되지 않은 가격 변경을 자동 확정하지 않으며 재검증 대상으로 표시합니다. 신규 후보의 검증 가능 가격만 `enrich_official.py`로 자동 확정합니다.
5. **결과물:** `index.html`은 인터넷/서버 없이도 이미 저장된 병원 목록 검색·가격 비교·CSV 및 JSON 내보내기·로컬 수정을 할 수 있습니다. **단, 새 SNS 정보를 가져오려면 Python 수집 프로그램을 실행하고 `build.py`로 다시 빌드해야 합니다.**

## 바로 실행 (Android/Pydroid 불필요)

`index.html`을 Chrome 등 브라우저로 엽니다. 기본 비교 용량은 10mg이며, 지역·외국인 처방·온라인·전국 배송·행사가·SNS 발굴 필터를 쓸 수 있습니다. `일본전국배송`은 일본 국내 배송 가능을 뜻하며, 한국으로 국제배송을 뜻하지 않습니다. 통화는 모두 **일본 엔(¥)** 입니다. 개인 수정 내용은 해당 브라우저 저장소에 남으므로 JSON 백업 기능을 권장합니다.

## 매일 신규 병원 발굴을 자동 실행하려면

1. ZIP 안의 파일과 `.github/workflows/price-check.yml`을 **GitHub 저장소 최상위**로 업로드하고 Actions를 활성화합니다. 저장소 설정의 Actions Workflow permissions에서 필요한 경우 `Read and write permissions`를 부여합니다.
2. GitHub 저장소의 **Actions → Find new clinics from public SNS/web and monitor price sources → Run workflow**로 최초 1회 실행합니다. 이후 매일 **UTC 03:00 / 한국·일본 12:00(정오)**에 자동 실행됩니다(서버 부하에 따라 시작 시각이 지연될 수 있음).
3. 성공 시 `catalog.json`, `discoveries.json`, `catalog.csv`, `index.html`, `monitor.js` 등이 커밋되어 변경됩니다. 업데이트된 HTML은 저장소에서 다시 내려받아 열거나 GitHub Pages 정적 사이트에 공개해 조회할 수 있습니다.
4. 저장소가 비공개여도 GitHub Actions 권한 설정이 필요합니다. GitHub Pages 배포를 원한다면 Pages 설정과 공개 범위의 개인정보 유의가 필요합니다. 추적기는 별도의 이메일/푸시 자동 발송 기능을 포함하지 않습니다.

**중요한 제한:** 로그인/비공개 SNS 내용, 색인되지 않은 게시물은 수집하지 못합니다. 검색 서비스가 차단·빈 결과를 반환할 수 있으며 이때 `discoveries.json`의 `source_status` 및 화면에 성공/실패가 나타납니다. 이 환경에서는 GitHub에서 실시간 수집을 직접 실행하지 못했으며, 코드의 로컬 파서 자가검사만 통과했습니다. 새 병원명은 게시글만으로 진짜 병원인지 확정할 수 없어서 후보로 표시합니다. 이벤트 검색 게시글만으로 12펜 할인 가격을 확정하지 않습니다.

## 수동 실행 (네트워크가 되는 PC 또는 GitHub Actions)

```bash
pip install -r requirements.txt
python discover.py
python enrich_official.py
python watch_sources.py
python build.py
```

간단 테스트는 다음과 같습니다.

```bash
python discover.py --self-test
python enrich_official.py --self-test
```

## 데이터 구성

- `catalog.json`: 정가 6개 용량, 외국인·비대면·전국배송, 지역/조건/출처, `events[]`(별도 기간/가격), `discovery`(발견 출처), `status`.
- `discoveries.json`: 공개 SNS 검색을 통해 확보한 원문 URL, 후보명, 행사 단서, 각 검색 서비스 성공/실패, 마지막 시각.
- `catalog.csv`: 기존 정가 및 행사 가격 6개 용량씩과 이벤트 기간, 조건, 지역, 출처.
- `japan_mounjaro_12weeks.xlsx`: 이번 조사 기준 Excel 스냅샷. 시트에 날짜 기반 행사 유효가 계산식을 포함. **GitHub 자동 워크플로는 HTML/CSV/JSON만 갱신하며 XLSX는 자동 갱신하지 않습니다.**
- `index.html`: 데이터가 내장된 단일 파일 (오프라인 사용). 신규 SNS 자동 검색은 이 HTML 자체에서 실행되지 않음.

## 가격 범위·행사 예시

- CKK 온라인: 10mg **82,500엔 / 12펜**, 쿨배송비 2,000엔 별도(원거리 3,500엔).
- 야마모토 요나고: 10mg **96,000엔 / 12펜 환산**, 공식 4펜 32,000엔×3, 주문발주/일괄 처방 확인 필요.
- ORIGAMI: 10mg **138,000엔 / 12펜 환산**, 4펜 46,000엔×3.
- PIQUÉ: 2.5mg **21,500엔**, 5mg **43,000엔 / 각각 12펜**; 예약 플랫폼 한정, **2026-11-30 종료 예정**.
- SDH: 2.5mg 20,700엔 / 12펜(11/15 종료한 SNS 이벤트 기록) vs 현재 일반 29,400엔. 과거 행사는 기본 현재가 비교에서 제외.

진찰료, 재진료, 배송비, 할인 중복 조건, 주사 준비 수량, 관광객 처방 가능 여부가 전부 확인된 것은 아닙니다. 12주 환산값은 12펜 일시 수령 허용 여부를 보장하지 않습니다.
