- **출처/이용 조건:** 후생노동성 자료는 [공공데이터 이용약관 PDL 1.0](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/newpage_43373.html)에 따른 공개 데이터이고, 사야카·미라이는 탐색용 참고 링크로만 취급합니다. 국가 공공데이터와 타사 비교사이트를 동일한 권리의 자료로 간주하지 않습니다.

## 2026-11-21: 재검색 변경 이력 + 공식가·홍보가 분리 (v6)

- **재검색 변경 내역:** `scan_changes.py`가 매회 검색 시작 전후의 병원 목록·공식 가격·홍보물·기본 조건·공식 출처 페이지 해시를 비교합니다. 최근 30회 기록이 `scan_changes.json`에 남고, 사이트 상단 **재검색 후 달라진 내용**에서 신규 병원·공식 가격 변동·홍보물 신규 발견·공식 페이지 변경 여부를 보여줍니다. 비교표에는 **재검색 변경** 표시와 **이번 재검색 변경 병원만** 필터를 제공합니다. 원문 페이지 변화는 **가격 변경 확정이 아니라 재확인 신호**입니다.
- **가격 표기 분리:** `prices`의 공식 기본가를 우선 표시합니다. 공식가와 다른 홍보가 또는 홍보가만 있는 항목은 별도 **홍보물** 표시로 12주 금액, 게시일(확인 가능할 때), 발견일, 출처 링크를 노출합니다. 4펜 가격만 명시된 홍보물은 원래 4펜 가격과 12펜 단순 환산값을 구분합니다. 홍보물 가격은 검증된 공식 가격 순위에 **합산하지 않습니다**.
- **SNS 공개 광고 추출:** `collect_promotions.py`는 공개 SNS 원문에서 병원명이 유일하게 확인되고 용량·엔 가격·포장 수량(4펜/12펜)이 모두 명확한 게시물만 `promotions[]`에 저장합니다. `prices`를 덮어쓰지 않습니다. 검색결과에 게시일이 없으면 **게시일 미확인 · 발견일**로 표기하며, 광고 날짜를 임의로 추측하지 않습니다. 같은 날짜의 기존 공개 이벤트는 `events[]`에서 계속 구분됩니다.
- **워크플로:** 매일 한국시간 정오 자동 검색 및 수동 심층 검색에 변경 비교를 연결했습니다. 데이터 커밋만으로 수집기가 다시 시작되는 반복 실행을 방지하려고 `catalog.json`을 GitHub Actions의 `push.paths`에서 제외했습니다. 새 결과를 보려면 검색 완료 후 웹사이트의 **최신 결과 불러오기**를 누릅니다.

- 정적 사이트 자체에 백엔드 비밀 인증키를 저장하지는 않았습니다. 토큰 기반 기능은 개인용으로 최소 권한을 설정하되, 토큰 입력 페이지의 보안 및 본인 브라우저 환경을 신뢰해야 합니다.

## 요구사항별 동작

1. **병원 발굴부터:** `discover.py`가 공식 병원 사이트 검색, 공개 SNS 색인(X·Instagram·Facebook 등), 공개 Yahoo! Japan X 실시간 검색 및 Google News RSS, 공개 비교 사이트 병원 목록을 조회합니다. 검색 결과에서 병원명을 인식하면 `catalog.json`에 중복을 걸러 새로운 **candidate** 레코드를 만듭니다. 이름, 공식 후보 URL 또는 공개 링크, 발견 경로를 기록합니다. 신규 병원은 소스코드의 고정 목록에 미리 등록할 필요가 없습니다.
2. **발견된 병원의 가격 검증:** `enrich_official.py`가 새 후보의 직접 발견한 공식 페이지를 우선 확인하고, 없는 경우 병원명으로 공식 가격표를 검색한 후, **12펜/3개월 가격이 명시되어 있거나 4펜/1개월 가격이 분명할 때에만** 12주 값을 추출해 비교표에 채웁니다. 가격을 안전하게 판별할 수 없다면 `후보·가격검증 전` 상태로 남깁니다. 외국인 수진, 온라인 진료, 전국 배송은 **근거 없이 '가능'으로 자동 분류하지 않습니다.**
3. **이벤트도 가격에 포함:** `catalog.json`의 `events[]`에 12펜 행사 금액, 기간, 조건, 출처를 별도로 넣습니다. 기간 내 행사 금액은 **공식가와 별도의 홍보·이벤트 가격**으로 표시됩니다. 화면에서 `홍보물·이벤트`로 표시하며, 행사 종료 시 종료 여부와 날짜를 함께 남깁니다. 행사 가격은 공식 최저가 정렬에 반영하지 않습니다. **이미 종료된 행사 및 유효성이 확인되지 않은 홍보물은 현행 공식 최저가로 오인되지 않도록 구분합니다.**
4. **기존 가격 추적:** `watch_sources.py`는 등록된 공식 가격 페이지 내용의 변경을 감시합니다. 검증되지 않은 가격 변경을 자동 확정하지 않으며 재검증 대상으로 표시합니다. 신규 후보의 검증 가능 가격만 `enrich_official.py`로 자동 확정합니다.
5. **결과물:** `index.html`은 인터넷/서버 없이도 이미 저장된 병원 목록 검색·가격 비교·CSV 및 JSON 내보내기·로컬 수정을 할 수 있습니다. **단, 새 SNS 정보를 가져오려면 Python 수집 프로그램을 실행하고 `build.py`로 다시 빌드해야 합니다.**

## 바로 실행 (Android/Pydroid 불필요)

`index.html`을 Chrome 등 브라우저로 엽니다. 기본 비교 용량은 10mg이며, 지역·외국인 처방·온라인·전국 배송·행사가·SNS 발굴 필터를 쓸 수 있습니다. `일본전국배송`은 일본 국내 배송 가능을 뜻하며, 한국으로 국제배송을 뜻하지 않습니다. 통화는 모두 **일본 엔(¥)** 입니다. 개인 수정 내용은 해당 브라우저 저장소에 남으므로 JSON 백업 기능을 권장합니다.

## 매일 신규 병원 발굴을 자동 실행하려면

1. ZIP 안의 파일과 `.github/workflows/price-check.yml`을 **GitHub 저장소 최상위**로 업로드하고 Actions를 활성화합니다. 저장소 설정의 Actions Workflow permissions에서 필요한 경우 `Read and write permissions`를 부여합니다.
2. GitHub 저장소의 **Actions → Find new clinics from public SNS/web and monitor price sources → Run workflow**로 최초 1회 실행합니다. 이후 매일 **UTC 03:00 / 한국·일본 12:00(정오)**에 자동 실행됩니다(서버 부하에 따라 시작 시각이 지연될 수 있음).
3. 성공 시 `catalog.json`, `discoveries.json`, `catalog.csv`, `index.html`, `monitor.js` 등이 커밋되어 변경됩니다. 업데이트된 HTML은 저장소에서 다시 내려받아 열거나 GitHub Pages 정적 사이트에 공개해 조회할 수 있습니다.
4. 저장소가 비공개여도 GitHub Actions 권한 설정이 필요합니다. GitHub Pages 배포를 원한다면 Pages 설정과 공개 범위의 개인정보 유의가 필요합니다. 추적기는 별도의 이메일/푸시 자동 발송 기능을 포함하지 않습니다.

**중요한 제한:** 로그인/비공개 SNS 내용, 색인되지 않은 게시물은 수집하지 못합니다. 검색 서비스가 차단·빈 결과를 반환할 수 있으며 이때 `discoveries.json`의 `source_status` 및 화면에 성공/실패가 나타납니다. 이 환경에서는 GitHub에서 실시간 수집을 직접 실행하지 못했으며, 코드의 로컬 파서 자가검사만 통과했습니다. 새 병원명은 게시글만으로 진짜 병원인지 확정할 수 없어서 후보로 표시합니다. 이벤트 검색 게시글만으로 12펜 할인 가격을 확정하지 않습니다.

## 수동 실행 (네트워크가 되는 PC 또는 GitHub Actions)

```bash
pip install -r requirements.txt
python discover.py
python enrich_official.py
python watch_sources.py

```


## 데이터 구성

- `catalog.json`: 정가 6개 용량, 외국인·비대면·전국배송, 지역/조건/출처, `events[]`(별도 기간/가격), `discovery`(발견 출처), `status`.
- `discoveries.json`: 공개 SNS 검색을 통해 확보한 원문 URL, 후보명, 행사 단서, 각 검색 서비스 성공/실패, 마지막 시각.
- `catalog.csv`: 기존 정가 및 행사 가격 6개 용량씩과 이벤트 기간, 조건, 지역, 출처.
- `japan_mounjaro_12weeks.xlsx`: 이번 조사 기준 Excel 스냅샷. 시트에 날짜 기반 행사 유효가 계산식을 포함. **GitHub 자동 워크플로는 HTML/CSV/JSON만 갱신하며 XLSX는 자동 갱신하지 않습니다.**
- `index.html`: 데이터가 내장된 단일 파일 (오프라인 사용). 신규 SNS 자동 검색은 이 HTML 자체에서 실행되지 않음.

## 가격 범위·행사 예시

- CKK 온라인: 10mg **82,500엔 / 12펜**, 쿨배송비 2,000엔 별도(원거리 3,500엔).
- 야마모토 요나고: 10mg **96,000엔 / 12펜 환산**, 공식 4펜 32,000엔×3, 주문발주/일괄 처방 확인 필요.
- ORIGAMI: 10mg **138,000엔 / 12펜 환산**, 4펜 46,000엔×3.
- PIQUÉ: 2.5mg **21,500엔**, 5mg **43,000엔 / 각각 12펜**; 예약 플랫폼 한정, **2026-11-30 종료 예정**.
- SDH: 2.5mg 20,700엔 / 12펜(11/15 종료한 SNS 이벤트 기록) vs 현재 일반 29,400엔. 과거 행사는 기본 현재가 비교에서 제외.

진찰료, 재진료, 배송비, 할인 중복 조건, 주사 준비 수량, 관광객 처방 가능 여부가 전부 확인된 것은 아닙니다. 12주 환산값은 12펜 일시 수령 허용 여부를 보장하지 않습니다.
